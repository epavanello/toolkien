# Directory candidates

Servers looked at for `directory/servers/` on 2026-11-14 and left out, with the reason. Sources: Anthropic's connectors directory, the official MCP Registry (`registry.modelcontextprotocol.io`), vendor docs, `modelcontextprotocol/servers`. Every endpoint below was probed with an unauthenticated `initialize` (`POST`), then its RFC 9728 / RFC 8414 metadata was read to check for dynamic client registration (DCR) and CIMD. No OAuth client was registered anywhere.

## Not yet supported
